# Mozillion for Home Assistant

Custom integration for Home Assistant that fetches your [Mozillion](https://www.mozillion.com/) mobile data usage — how much you've used and how much is remaining.

## Features

- Config flow for easy setup
- Supports manual cookies + XSRF token
- Supports automated login with email/password and optional TOTP secret
- Two sensors: usage and remaining, plus raw payload attribute
- Connectivity binary sensor
